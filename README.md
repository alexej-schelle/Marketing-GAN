# 📊 Marketing GAN 

---

## 🏫 Project & Repository Description 

📘 The goal of this project, developed as part of the course **"Data Modeling and Database Systems"**, is to develop a **concept for a GAN (Generative Adversarial Network)** that can predict sales numbers for specific sales periods. The files in this repository provide a collection of the basic Python routines required for this task. 

The project includes the modeling of sales data using **statistical distributions** and the prediction of sales figures for real-world datasets such as **Adidas** and **Rossmann**.

## 🎓 Documented Application Scenarios 

---

* 🔮 **Predicting sales numbers** for the Adidas dataset (CC0 1.0 Universal License).

---

## 📂 Overview and Component Descriptions 

---

* 🧑‍💻 **GAN.py**: Models sales data by comparing sales numbers from randomly generated data with original data using a **GAN**. The **generator** and **discriminator** are two components of the GAN, each modeled by an artificial neural network. 
* 🧑‍💻 **Rossmann*.py**: Models sales data using an **SVM** model. 
* 🧑‍💻 **SyntheticDataGenerator.py**: Generates synthetic sales data based on a uniform distribution. 
* 🧑‍💻 **VisualizeAdidasSalesData.py**: Analyzes the **adidas_dataset_new.csv** dataset from Adidas (source: see Kaggle.com).

## 📂 Übersicht und Beschreibung der Komponenten 

---

* 🧑‍💻 **GAN.py**: Modelliert Verkaufszahlen durch den Vergleich von Verkaufszahlen aus zufällig generierten Daten und originalen Daten durch ein **GAN**. Generator und Diskriminator bilden zwei Komponenten im GAN, jede Komponente wird dabei durch ein künstliches neuronales Netzwerk modelliert. 
* 🧑‍💻 **Rossmann*.py**: Modelliert Verkaufszahlen durch ein **SVM** Modell. 
* 🧑‍💻 **SyntheticDataGenerator.py**: Modelliert künstliche Verkaufszahlen nach einer Gleichverteilung. 
* 🧑‍💻 **VisualizeAdidasSalesData.py**: Wertet den **adidas_dataset_new.csv** Datensatz der Firma Adidas aus (Quelle: siehe Kaggle.com).
